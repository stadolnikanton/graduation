# FileCloud 🚀

Облачное хранилище файлов с возможностью совместного доступа и временными ссылками для обмена.

## 📋 Описание

FileCloud — это полнофункциональное веб-приложение для хранения, управления и обмена файлами. Проект включает RESTful API на FastAPI, современный фронтенд и интеграцию с объектным хранилищем MinIO.

### Основные возможности

- 🔐 **Аутентификация и авторизация** — JWT токены с refresh механизмом
- 📤 **Загрузка файлов** — одиночная и множественная загрузка
- 📁 **Управление файлами** — просмотр, скачивание, удаление
- 👥 **Совместный доступ** — предоставление доступа другим пользователям с разными уровнями прав
- 🔗 **Временные ссылки** — создание ссылок для обмена с ограничением по времени и количеству скачиваний
- 🗄️ **Объектное хранилище** — интеграция с MinIO для масштабируемого хранения

## 🛠️ Технологический стек

### Backend

- **FastAPI** — современный асинхронный веб-фреймворк
- **SQLAlchemy 2.0** — ORM с асинхронной поддержкой
- **Alembic** — миграции базы данных
- **PostgreSQL** — реляционная база данных
- **MinIO** — объектное хранилище (S3-совместимое)
- **JWT** — аутентификация через токены
- **Argon2** — хеширование паролей
- **Pydantic** — валидация данных

### DevOps

- **Docker** — контейнеризация
- **Docker Compose** — оркестрация сервисов
- **Make** — автоматизация задач

## 📦 Требования

Перед началом работы убедитесь, что у вас установлены:

- **Docker** (версия 20.10+)
- **Docker Compose** (версия 2.0+)
- **Make** (опционально, для удобства)

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/stadolnikanton/graduation.git
cd graduation
```

### 2. Запуск проекта

```bash
# Сборка и запуск всех сервисов
make build
make up

# Или без Make:
docker-compose build
docker-compose up -d
```

### 3. Применение миграций

Миграции применяются автоматически при старте backend контейнера. Если нужно применить вручную:

```bash
make migrate
```

### 4. Доступ к сервисам

После запуска сервисы будут доступны по следующим адресам:

| Сервис            | URL                         | Описание                              |
| ----------------- | --------------------------- | ------------------------------------- |
| **Backend API**   | http://localhost:8000       | REST API                              |
| **API Docs**      | http://localhost:8000/docs  | Swagger UI                            |
| **ReDoc**         | http://localhost:8000/redoc | ReDoc документация                    |
| **MinIO Console** | http://localhost:9001       | Консоль MinIO (minioadmin/minioadmin) |
| **PostgreSQL**    | localhost:5433              | База данных                           |

## 📚 Управление проектом

Проект использует `Makefile` для упрощения работы с Docker-контейнерами.

### Основные команды

```bash
make help        # Показать все доступные команды
make build       # Собрать контейнеры без кэша
make up          # Запустить контейнеры в фоне
make start       # Запустить существующие контейнеры
make stop        # Остановить контейнеры
make restart     # Перезапустить контейнеры
make down        # Остановить и удалить контейнеры
make logs        # Просмотр логов всех сервисов
make status      # Статус контейнеров
```

### Работа с базой данных

```bash
make migrate                     # Применить миграции
make migrate-create message="msg" # Создать новую миграцию
make db-shell                    # Подключиться к PostgreSQL
```

### Тестирование

```bash
make test        # Запустить тесты
```

### Разработка

```bash
make shell       # Открыть bash в backend-контейнере
make db-shell    # Открыть psql в PostgreSQL
```

### Очистка

```bash
make clean       # Полная очистка (контейнеры, volumes, orphan-сервисы)
make volumes     # Список docker volumes
```

## 🔒 Безопасность

- **JWT токены** — access и refresh токены с настраиваемым временем жизни
- **Argon2** — современный алгоритм хеширования паролей
- **Blacklist токенов** — токены добавляются в черный список при выходе
- **Проверка прав доступа** — валидация прав пользователя на каждый запрос
- **SecretStr** — защищенное хранение секретов в конфигурации
- **CORS** — настроенная политика для безопасного взаимодействия с фронтендом

## 🔧 Конфигурация

Настройки приложения задаются через переменные окружения. Основные параметры:

### База данных

- `DB_HOST` — хост PostgreSQL (по умолчанию: `localhost`)
- `DB_PORT` — порт PostgreSQL (по умолчанию: `5432`)
- `DB_NAME` — имя базы данных (по умолчанию: `filecloud`)
- `DB_USER` — пользователь БД (по умолчанию: `filecloud_user`)
- `DB_PASSWORD` — пароль БД (по умолчанию: `filecloud_password`)

### JWT

- `SECRET_KEY` — секретный ключ для подписи токенов (обязательно)
- `ALGORITHM` — алгоритм подписи (по умолчанию: `HS256`)
- `ACCESS_TOKEN_EXPIRE_MINUTES` — время жизни access токена (по умолчанию: `30`)
- `REFRESH_TOKEN_EXPIRE_DAYS` — время жизни refresh токена (по умолчанию: `7`)

### MinIO

- `MINIO_ENDPOINT` — адрес MinIO сервера (по умолчанию: `minio`)
- `MINIO_ACCESS_KEY` — ключ доступа (по умолчанию: `minioadmin`)
- `MINIO_SECRET_KEY` — секретный ключ (по умолчанию: `minioadmin`)
- `MINIO_BUCKET_NAME` — имя bucket (по умолчанию: `uploads`)

Для продакшена создайте файл `.env` в корне проекта `backend/` с необходимыми значениями.

## 🐛 Решение проблем

### Контейнеры не запускаются

```bash
# Проверьте логи
make logs

# Проверьте статус контейнеров
make status

# Пересоберите контейнеры
make clean
make build
make up
```

### Ошибки подключения к БД

Убедитесь, что PostgreSQL контейнер запущен и здоров:

```bash
docker-compose ps postgres
```

### Проблемы с миграциями

```bash
# Примените миграции вручную
make migrate

# Или создайте новую миграцию
make migrate-create message="описание изменений"
```
